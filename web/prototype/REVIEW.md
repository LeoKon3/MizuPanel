# 独立样板验收

验收日期：2026-11-08。范围为 `web/prototype/` 与 `web/vite.prototype.config.ts`，需求依据本轮用户确认的 Q1–Q16 和最终样板授权。

## Standards

- 保持 React + TypeScript + Tailwind 与 Lucide，不增加应用运行依赖；复用现有 BrandLogo、Toast。
- 样板的样式和数据类型刻意局限于独立入口，不向生产 `styles.css` / `types.ts` 注入未验收设计。
- 生产入口、API client、后端和部署产物不修改，其他 agent 的已有改动不覆盖。
- 使用自定义对话框、键盘焦点圈定、Escape 关闭与焦点恢复；没有浏览器原生 alert/confirm/prompt。
- 外部连接由 CSP 禁止。模拟 IP 均为文档保留范围；本地保存和 AI 回复明确标注样板性质。
- 没有 Git 暂存、提交、tag 或发布；样板不算正式产品发布。
- Vitest 缓存定向到已忽略的 `web/node_modules/.vite-prototype/`。

## Spec

- 独立主机列表与详情、稳定名称排序、状态/分组/搜索、批量选择入口完整。
- 返回保留列表筛选和滚动位置；跨主机保留分区，重置目标数据与进程筛选。
- 文件编辑样板可验证未保存保护；浏览器后退取消后保留原历史位置。
- 概览承担趋势，进程页没有全局 KPI；数据零、离线和过期有独立表达。
- AI 抽屉覆盖而非挤压，显式打开，草稿和捕获上下文可跨完整工作台保留。
- 终端、添加主机、批量/分组及非样板页面保留诚实的范围说明，不伪装已接入。
- 真实 API、命令执行、凭据、AI 模型与业务保存均不在本轮范围。正式接入需另行确认。
